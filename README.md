# python-projects

Small standalone Python projects built for practice.

## Projects
- calculator/ - Command-line calculator (+, -, *, /)
- rock.py - Rock, Paper, Scissors game (functions, conditionals, random module)
- camel.py - Converts camelCase to snake_case (loops, string methods)
- coke.py - Coin machine that calculates change owed (loops, input validation)
- password_generator.py - Customizable password generator (loops, random/string modules, input validation)
- 🧮 Math Quiz Game — A command-line quiz with 3 difficulty levels (easy/medium/hard), randomized 
questions using +, -, *, and /, input validation, scoring out of 5, and a play-again loop.
